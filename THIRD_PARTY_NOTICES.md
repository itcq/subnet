# Third-Party Notices

The project does not currently declare a source-code license. Ownership and licensing remain an explicit open decision.

This repository depends on third-party open-source software. Each dependency remains governed by its own license and copyright notices. Dependency names and resolved versions are recorded in `package.json` and `package-lock.json`; installed package metadata contains the corresponding license terms.

The Expo starter template originally placed Expo's MIT license at the repository root. That template license was removed so it would not be mistaken for a licensing decision covering this application's original source code.

Before distribution, review all production dependencies, generate a complete third-party notice inventory, and publish any notices required by their licenses.
